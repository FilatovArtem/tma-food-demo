# CLIENT_DEMO — 60-секундный pitch для владельцев общепита

Готовый скрипт для показа демо клиенту. Цель: за минуту провести через каталог → AI-подбор → заказ → уведомление. Чтобы клиент сказал «хочу такой же, под мой ресторан».

---

## До демо: подготовка (5 минут)

- Бот развёрнут, туннель работает, WEBAPP_URL актуален в BotFather
- Открой бота на своём телефоне (показывать клиенту с большого экрана через mirroring или просто свой телефон)
- Открой Telegram на втором устройстве (или в Telegram Web) с **админ-чатом** — туда придёт уведомление о заказе. Это второй экран для «вау-эффекта»
- Менюшки в seed.json — реалистичные блюда из общепита, не учебные. Цены адекватные для региона клиента

---

## Скрипт демо (60 секунд)

### [0:00 — 0:05] Открытие

> «Покажу как ваши клиенты смогут заказывать у вас прямо в Telegram, без отдельного приложения»

→ открываешь бота в Telegram, **визуально показываешь чат с ботом**.

### [0:05 — 0:15] /start + Mini App

> «Клиент нажимает /start у вашего бота — видит кнопку открыть меню»

→ нажимаешь `/start` → появляется кнопка «🍽 Открыть меню» → тап.

> «Mini App открывается прямо в Telegram. Без скачиваний, без логинов, без email-подтверждений»

→ Mini App запускается за < 2 сек. Видны категории и блюда.

### [0:15 — 0:30] Каталог + детализация

> «Меню — табы по категориям, карточки с фото, ценами. Адаптируется под тёмную/светлую тему как родное приложение Telegram»

→ скролл по каталогу, переключение категорий, тап по блюду → детальная страница.

→ покажи **состав** и **КБЖУ** на детальной странице.

> «Кладёт в корзину»

→ тап +, индикатор корзины обновляется.

### [0:30 — 0:45] AI-подбор (killer feature)

> **«А теперь то, чего нет ни у кого. AI-подбор»**

→ возвращаешься на каталог → жмёшь «✨ Подобрать с AI».

> «Клиент пишет естественным языком — что хочет»

→ вводишь в поле: `что-то лёгкое до 400 рублей` → тап «Подобрать».

→ через 1-3 сек видны 2-3 блюда с пояснением «почему именно это». Тап «+» — добавляются в корзину.

> «AI читает ваше меню, понимает запрос, объясняет почему рекомендует. Конверсия выше — клиент не теряется в каталоге, AI помогает выбрать»

### [0:45 — 0:55] Заказ + уведомление

→ открываешь корзину → «Оформить заказ» → вводишь телефон → подтверждаешь.

> «Заказ оформлен. А теперь главное — вы получаете уведомление прямо в Telegram»

→ **достаёшь второй телефон / показываешь Telegram на ноуте** с админ-чатом → там сообщение:

```
🛒 Новый заказ #42
👤 Артём, +7 999 123-45-67

• Цезарь с курицей × 2 — 1040₽
• Латте — 280₽

💰 Итого: 1320₽
```

> «Ваш повар или менеджер видит заказ сразу. Можно сделать вход на нескольких людей — отправлять в общий чат»

### [0:55 — 1:00] Закрытие

> «Готовый продукт. Развернём под вас за 5-7 дней: ваше меню, ваш бренд, ваш бот. AI-подбор и уведомления уже встроены. Что у вас сейчас с приёмом заказов?»

→ молчи. Пусть клиент сам начнёт говорить.

---

## Что НЕ говорить во время демо

- **«Это open-source/проект на GitHub»** — клиент решит что бесплатно, цена обнулится
- **«Стек технологий»** — клиенту неинтересен React, FastAPI, OpenAI. Только результат
- **«MVP», «прототип», «демо»** — продай как готовый продукт. Это и есть готовый продукт под кастомизацию
- **Не показывай админку/код** — даже если попросят. «Под капотом» = твой ноу-хау

## Типичные возражения и ответы

### «А сколько стоит?»

> «Базовая настройка под ваш ресторан — `[твоя цена]` ₽, разворачивается за 5-7 дней. AI-подбор и уведомления включены. Если нужны платежи, многоэтапные статусы, доставка — обсуждаем отдельно»

### «Без AI нельзя?»

> «Можно. Но AI поднимает конверсию в среднем на 15-20% [если есть данные — сослись на них; если нет — скажи "по нашим тестам"], стоимость одного запроса меньше копейки. Поставка с AI = себестоимость почти та же, а выглядит как next-level»

### «А клиенты будут пользоваться Telegram-ботом?»

> «У вас в Telegram уже сейчас [X миллионов человек в РФ / 800 миллионов мире]. Никаких "установок", никаких "регистраций". В России Telegram давно вторая по охвату соцсеть — клиенту проще тапнуть Mini App, чем скачать ваше приложение»

### «У нас уже есть свой сайт/доставка»

> «Mini App — это не замена сайту, это дополнительный канал. Можно интегрировать с вашей админкой/POS, можно как отдельный канал. С маркетинговой кампанией в Telegram — заказы пойдут оттуда, где сейчас они не идут вообще»

### «Сколько будет ваших аналогов через год?»

> «AI-подбор сейчас никто на рынке не делает. Через год будут. Поэтому стоит запускать сейчас — пока вы первые в своей нише, можно занять рынок»

### «А оплата? Я хочу принимать деньги»

> «Платежи — отдельный модуль. Подключаем ЮKassa / Telegram Payments / СБП. Базовый MVP без платежей = быстрый запуск, проверка спроса. Если идёт — добавляем оплату через 2-3 дня»

### «А мобильное приложение лучше же?»

> «Лучше для тех, кто его установит. Но 70%+ клиентов отказываются качать приложение [статистика есть, если нужно — гугли]. Mini App работает прямо в мессенджере, который у клиента уже открыт. Зачем уговаривать установить, если можно использовать прямо сейчас»

## Follow-up после демо

В тот же день:

1. **Резюме в личку клиенту** (или в чат-выбор):
   ```
   Спасибо за встречу! Кратко что обсудили:
   - Telegram Mini App для вашего ресторана
   - AI-подбор блюд под запрос клиента
   - Уведомления о заказах в [личный чат / общий чат команды]
   - Срок: 5-7 дней с момента передачи материалов (меню, лого, цвета)
   - Цена: [сумма] ₽

   Что нужно от вас для старта:
   • Текущее меню (PDF/Excel/ссылка)
   • Лого + основной цвет бренда (если есть)
   • Логин/название будущего бота (например, @yourrestaurant_bot)

   Готовы стартовать? Запущусь сегодня же.
   ```

2. **Если молчат 24-48ч** — мягкий follow-up:
   ```
   Привет, [имя]! Не получилось пересмотреть наш разговор? Если есть вопросы по сумме/срокам/функционалу — давайте обсудим в звонке.
   ```

3. **Если отказ** — спроси причину:
   ```
   Понял. Подскажите что не подошло — цена, технология, тайминги? Может быть смогу скорректировать предложение
   ```

## Чек-лист готовности к демо

- [ ] Бот работает (`/start` отвечает в Telegram)
- [ ] Mini App открывается на твоём телефоне < 2 сек
- [ ] Туннель ngrok жив (проверь URL в браузере перед встречей)
- [ ] Минимум 1 тестовый заказ прошёл за последний час (не залежавшийся)
- [ ] Админ-чат открыт на втором устройстве с уведомлениями
- [ ] OpenAI баланс > $1 (AI не упадёт в fallback в самый важный момент)
- [ ] Wi-Fi устойчивый или мобильный интернет с запасом

---

## Версионирование демо

Меняй seed.json под клиента **до встречи**: его кухня, его средний чек. Если у клиента ресторан грузинской кухни — не показывай ему пасту карбонара. Заранее адаптируй меню (это 5 минут — список блюд в JSON), это удвоит вероятность сделки.
